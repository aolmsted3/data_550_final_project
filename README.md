# DATA 550: Analysis of Simulated EFGH Data

This is the Github repository which contains all code for the final project analysis. The repository contains the following subfolders:

Raw_data: contains a simulated version of the Enterics for Global Health (EFGH) dataset.

Code: includes R scripts to generate the table and figure required for report rendering.

Output: contains outputted files from R scripts (i.e., table and figure).

The repository includes a Makefile which can be used to render the report (make efgh_report.html).
